# Как опубликовать comments-parser.ru и отправить его в индекс Google

Сайт уже настроен под домен **comments-parser.ru** (canonical, og:url, JSON-LD, sitemap.xml,
robots.txt — везде прописан этот адрес). Ниже — самый быстрый бесплатный способ разместить
статичный HTML-сайт на этом домене через GitHub Pages.

## 1. Создайте репозиторий на GitHub

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта)
2. Создайте новый репозиторий, например `comments-parser`
3. Загрузите туда четыре файла: `index.html`, `robots.txt`, `sitemap.xml` и файл `CNAME`
   (создать его — см. шаг 2) — через веб-интерфейс: "Add file" → "Upload files"

## 2. Создайте файл CNAME

В корне репозитория создайте файл с именем `CNAME` (без расширения), содержащий одну строку:

```
comments-parser.ru
```

Это указывает GitHub Pages, на какой домен отвечать.

## 3. Включите GitHub Pages

1. В репозитории откройте **Settings → Pages**
2. "Build and deployment" → **Deploy from a branch**
3. Branch: `main`, папка `/root` → **Save**
4. В поле **Custom domain** введите `comments-parser.ru` → **Save**
   (GitHub попросит настроить DNS — это шаг 4)

## 4. Настройте DNS у регистратора домена (reg.ru)

В панели управления доменом comments-parser.ru на reg.ru добавьте DNS-записи:

**A-записи** (для самого домена comments-parser.ru) — добавьте все четыре:
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**Если также нужен www.comments-parser.ru** — добавьте CNAME-запись:
```
www → ваш-логин.github.io.
```

DNS обновляется от нескольких минут до 24–48 часов. После этого в GitHub Settings → Pages
появится галочка и станет доступен чекбокс **Enforce HTTPS** — включите его (сертификат
выпускается автоматически, обычно занимает до часа).

## 5. Проверьте, что сайт открывается

Откройте https://comments-parser.ru в браузере — должна загрузиться готовая страница рейтинга.

## 6. Отправьте сайт в Google Search Console

1. Зайдите на https://search.google.com/search-console
2. Добавьте ресурс типа **"Домен"** (не "Префикс URL") — введите `comments-parser.ru`.
   Google попросит подтвердить владение через TXT-запись в DNS (это надёжнее, чем через
   HTML-тег, и разово настраивается у того же регистратора, что и шаг 4)
3. После подтверждения откройте **Sitemaps** в левом меню и отправьте:
   `https://comments-parser.ru/sitemap.xml`
4. Во вкладке **URL Inspection** вставьте `https://comments-parser.ru/` и нажмите
   **"Запросить индексирование"** — это ускоряет первое сканирование

## 7. Про попадание в ChatGPT / OpenAI и другие LLM

Прямого способа "отправить сайт в OpenAI" не существует — модели вроде ChatGPT либо обучены
на данных с определённой датой отсечения (новый сайт они попросту не увидят), либо при ответе
с доступом в интернет используют живой веб-поиск (в т.ч. Bing и сторонние индексы). Единственный
рабочий рычаг — стандартное SEO: чем быстрее и качественнее сайт проиндексирован Google/Bing и
чем больше на него ссылок и упоминаний, тем выше шанс, что его найдёт и процитирует поисковая
надстройка LLM. HTML уже подготовлен под это: структурированные данные (Schema.org `Article`,
`ItemList`, `FAQPage`), прямой ответ в первом абзаце (BLUF) и таблица сравнения — то, что чаще
всего цитируют AI-обзорщики.

## 8. Что сделать дальше для роста трафика и цитируемости

- Добавьте сайт в Yandex.Webmaster (https://webmaster.yandex.ru) — для российской аудитории
  это не менее важно, чем Google Search Console
- Добавьте сайт в Bing Webmaster Tools (https://www.bing.com/webmasters)
- Получите несколько внешних ссылок (например, упомяните сайт в статье на vc.ru/dtf.ru/Habr)
- Раз в 1–3 месяца обновляйте цены/данные в таблице и меняйте `dateModified` в JSON-LD и
  `lastmod` в sitemap.xml — свежий контент индексируется и цитируется охотнее
